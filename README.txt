SHREYANSHI (BHUMI) BIRTHDAY WEBSITE

Files:
- index.html       Homepage and welcome message
- greetings.html   Birthday wishes and blessings
- gallery.html     Photo gallery
- style.css        Design and responsive mobile layout
- script.js        Small navigation enhancement
- assets/          Photos used by the website

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the folder.
3. Tap or double-click index.html to open the website in a browser.

HOW TO PUBLISH ON GITHUB PAGES:
1. Create a GitHub repository.
2. Upload all files and the assets folder (keep the folder structure).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the website and open the URL shown there.

This is a static website. It does not collect personal information or need a server.
